# 市場雷達

每天收盤後自動掃描台股（上市＋上櫃，含 ETF）和美股（S&P 500＋S&P 400＋常見 ETF），依「核心／衛星／戰術」三層架構整理成五頁：

| 頁面 | 對應 | 內容 |
|---|---|---|
| ① 總覽 | 戰術層 | 債務週期位置、資金風向、戰術層訊號、總經指標、大盤 vs 週線年線、總經×財報一致性、大盤估值與長線燈號 |
| ② 熱點 | 衛星層：發現 | 類股相對強弱、資金流入流出、類股×週熱力圖 |
| ③ 產業財報 | 衛星層：確認 | 產業營收年增、毛利率與淨利趨勢、公司財報判定（AI 摘要預留） |
| ④ 候選清單 | 衛星層：進出 | 四道濾網（熱點→資金流→財報→買點）、長線存股／波段模式、持股檢討、燈號回測 |
| ⑤ 核心配置 | 核心層 | 全天候目標 vs 實際、本月定投分配、再平衡提醒、三層總覽、決策日誌、核心層回測 |

自選股、持股、核心配置和決策日誌只存在瀏覽器 localStorage，可在⑤匯出備份。

- 網站：`index.html`（GitHub Pages）
- 每日更新：`.github/workflows/daily.yml`
  - 台股：台灣時間週一到週五 22:10
  - 美股＋總經＋核心配置回測：台灣時間週二到週六 06:30
- 計算程式：`scripts/update.py`（`--market tw | us | macro`）、`scripts/core_backtest.js`（全天候核心層回測，Node 18 以上）
- 資料：`data/`（程式自動產生，不要手動改）

## 介面設計

設計系統「Glass Terminal」，依用途切換三種材質：

- **毛玻璃**：側欄、頂部狀態、彈出視窗、提示、浮動控制、①總覽三大訊號
- **墨版**（深梅色＋細顆粒＋點線）：②產業熱點地圖、熱力圖。淺色模式下仍維持深色，像印在白紙上的海報
- **實心面板**：表格、清單、數字條、設定

字體 Noto Sans TC＋JetBrains Mono（數字），襯線引言用 Noto Serif TC。右下角 **Tweaks** 可切換深色／淺色、舒適／緊湊、紫／琥珀強調色、跑馬燈顯示與否。網站會記住上次造訪時的燈號，資料更新後有變化的股票會標一個小點。

舊版介面保留在 `archive/index-v2.html`。

## 台股官方資料（證交所／櫃買中心開放 API、FinMind）

- 休市日（`holidaySchedule`）：市場狀態與更新排程跳過國定假日
- 當日收盤（`STOCK_DAY_ALL`、櫃買 `tpex_mainboard_daily_close_quotes`）：核對 Yahoo 的台股價格，Yahoo 缺最新一天就補上，差超過 2% 標示「價格待確認」
- 每天累積：加權股價報酬指數（含息，`MFI94U`）、外資產業持股比率（`MI_QFIIS_cat`）；除權息預告（`TWT48U_ALL`）標在個股
- 大盤三大法人歷史：快取不足時用 FinMind 一次回補（不需金鑰）
- 上櫃個股法人歷史：設定 GitHub Secret `FINMIND_TOKEN`（FinMind 免費金鑰）後才會回補，每次最多 300 檔
- 大盤回測排除不含息的價格指數（加權指數、S&P 500、那斯達克100）

## TradingView 整合（免費）

- 頂部跑馬燈、個股視窗的「TradingView 圖表」「技術分析」「財務」分頁使用 TradingView 嵌入式小工具
- 個股的 20 年走勢圖使用 TradingView Lightweight Charts（開源）畫我們自己的資料
- 台股的 TradingView 主圖表受授權限制無法嵌入，改為連結到 TradingView 網站；台股的技術分析、財務小工具可正常顯示

## 總經判斷規則（①總覽）

資料來自 FRED：10Y−2Y 殖利率差、高收益債信用利差、10年期實質利率、預期通膨、美元指數。

- 債務週期：信用利差 ≥ 6% 或 3 個月急升 1.5% → 衰退；殖利率曲線倒掛 → 緊縮；近兩年曾倒掛、曲線 < 0.5% 或利差 ≥ 4.5% → 擴張後期；其他 → 擴張初期
- 資金風向：美國景氣循環類股 ETF 減防禦類股 ETF 的近 4 週報酬差，±2% 以上判定偏冒險／偏避險
- 戰術層訊號：總經轉壞（曲線近半年由負轉正，或利差 3 個月急升 1.5%）**且**大盤週線跌破 MA52

## 核心層回測

`scripts/core_backtest.js` 由原本的 `backtest.js` 改來，輸出 `data/core.json`（網站用）和 `data/core_report.html`（完整報告）。另外加了資料清理：Yahoo 的 0050 拆股前價格沒有調整（2014 年前價格除以 4）、USD/TWD 匯率有異常值（2014-12 出現 3.67）。沒清理前的結果完全不能用。資料從 2009 年開始，沒有包含 2008 年。

手動更新：GitHub → Actions → 每日更新市場資料 → Run workflow。

## 分數怎麼算

| 分數 | 內容 |
|---|---|
| 價格位置 | 年線乖離、月KD（只用已收完的月份）、距5年高點回撤、5年位置 |
| 估值 | 本益比、股價淨值比跟同族群中位數比較，加上自由現金流殖利率、殖利率 |
| 品質 | ROE、淨利率、營收成長（台股用今年累計月營收年增）、負債比、自由現金流 |
| 長線總分 | 價格 40%＋估值 30%＋品質 30%；ETF 和指數只看價格位置 |
| 資金（波段模式） | 量能、族群資金比重、法人連買（台股）或相對大盤強弱（美股） |

品質低於 35 或虧損的個股，就算價格便宜也會亮「基本面弱」，總分最多 50。

基本面來自 Yahoo Finance，每檔最多 7 天更新一次（快取在 `data/cache/fund_*.json`），第一次執行會比較久。

## 燈號回測

網站上的「燈號有沒有用？」用 20 年月線重算每個月的價格燈號，統計之後 1、3、5 年的報酬中位數。只回測價格燈號（沒有歷史財報），而且有存活者偏差。

## 燈號變化通知（選填）

到 GitHub → Settings → Secrets and variables → Actions 新增：

- `TELEGRAM_BOT_TOKEN`：跟 @BotFather 建立機器人取得
- `TELEGRAM_CHAT_ID`：你的聊天 ID

沒設定也沒關係，變化紀錄一樣會寫進 `data/alerts.json` 並顯示在網站上。

## 本機測試

```
MR_DATA_DIR=/tmp/mr python scripts/update.py --market tw --limit 60
```

`--limit` 只跑少量個股，`MR_DATA_DIR` 讓輸出不要蓋掉正式資料。

本專案只整理公開資料、計算指標，不是投資建議。
